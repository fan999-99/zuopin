# FAN的折屋 · 作品集

静态作品集网站，在线浏览：

**https://fan999-99.github.io/zuopin/**

打开即可进入折纸小屋。屋里有印刷间、画室、摄影棚、游戏厅和门口信箱。

也可以把仓库克隆下来，直接打开根目录的 `index.html`（不需要服务器）。`images/`、`videos/` 要和 `index.html` 放在一起。作品图在 `index.html` 里另外内嵌了一份（长边 1600px），Bose 视频也内嵌了一份 720p 小版本；和 `videos/bose.mp4` 放在一起时，播的是原画质的那份。

## 换图片

1. 把图片放进对应文件夹，文件名和配置里的 `src` 一致（`01.jpg`、`02.jpg`……）。建议长边 2000px 左右、JPG 质量 80 上下，网页打开更快。
2. 打开 `index.html`，找到最上面的 `const PORTFOLIO = {`，每件作品是一个系列：
   ```js
   { title: '榴莲系列海报', year: '', type: '电商海报', tags: ['电商', '系列'], desc: '系列说明……',
     imgs: [
       { src: 'images/posters/04.jpg', w: 1268, h: 1794, cap: '榴莲月饼' },
       { src: 'images/posters/05.jpg', w: 1268, h: 1794, cap: '鲜榴莲' }
     ] }
   ```
   `w / h` 是图片的原始像素宽高（决定显示比例，不裁切）；`cap` 是这一张的小标题，可以空着。改完保存、刷新即可。
3. 图片不存在时会自动显示「作品图 01 · 放这里」占位框，不会出现破图。
4. 换了/新加的图片不在内嵌的那份里，所以要和 `index.html` 一起放在 `images/` 文件夹里。

| 房间 | 主角物件 | 文件夹 | 空占位框比例 |
| --- | --- | --- | --- |
| 印刷间 · 海报 | 晾晒绳（木夹） | `images/posters/` | 3:4 |
| 画室 · 插画 | 速写本（翻页、纸胶带、旁边的滚轮） | `images/illustration/` | 4:3 |
| 摄影棚 · 电商/AI 产品图 | 看片灯箱（幻灯片框） | `images/product/` | 1:1 |
| 游戏厅 · 互动/游戏 | 街机（卡带） | `images/interactive/` + `videos/` | 4:3 |
| 门口信箱 · 关于我 | 一封信（贴头像照片） | `images/about/avatar.jpg` + 改 `letter` 字段 | 头像约 7:10 |

- 有图时一律按图片自己的比例（`w / h`）显示，房间里、速写本里、放大后都不裁切；放大时最多放到原图大小。
- 上表比例只用于还没放图的占位框。

## 看图

- 点作品图放大，左上角显示「1 / 3」。放大后滚轮也分区：在**图上**滚 = 换这一件里的上一张 / 下一张（到头不再翻到下一件）；在**右边文字上**滚 = 只滚说明；在这两块外面滚 = 换上一件 / 下一件。← → ↑ ↓ 键也可以；手机左右滑；Esc、右上角 × 或点空白处关闭。
- 房间里滚轮也是同一套分区（电脑）：
  - 画室速写本：左页（图）滚 = 把叠在一起的画换到最上面一张；右页（文字）滚 = 只滚说明，滚到头也不会翻页；左页、右页外面滚 = 和方向键一样换房间。点最上面那张放大看，点后面露出来的那张会抽到最上面。书签、下一页按钮、旁边的滚轮仍然翻作品。
  - 印刷间等：在作品图上滚 = 换这一组里的图（封面图跟着换）；在标题文字上滚不会换房间；在空白处滚 = 换上一间 / 下一间。

## 视频（游戏厅 · Bose 静界）

- 视频放在 `videos/`，作品里写 `video: 'videos/bose.mp4'`，`img` 写封面图（`images/interactive/bose-poster.jpg`）。
- 卡带上会出现「播放」标，点开直接播放（有声音），关掉自动停止。`url` 写线上地址时，左边会有「打开看看 ↗」。
- Bose 耳机右边还有「玩玩互动 ↗」，打开本地的互动页 `interactive/bose-anjing.html`（只打开了 index.html 时也会打开内嵌的同一份）。
- 换视频：直接用同名文件替换 `videos/bose.mp4`。建议 H.264 编码的 MP4（手机、电脑都能播）。

## 画室 · 速写本

- 点右页（或右下角卷角、「下一页 →」）翻到下一页；点左页空白处翻回上一页；右侧书签可直接跳页；最后一页再点会翻回第一页。
- 速写本左边的小滚轮显示现在翻到第几张：每翻一页，滚轮转一下、刻度跟着走；鼠标放在本子上滚动滚轮也能翻页，点滚轮上半/下半也行。
- 点画面本身是放大看图。

## 关于我（信）

- 简历在 `letter.sections` 里，每段 `h` 是小标题，`items` 是「时间 + 内容」，`body` 是整段文字。
- 联系方式在 `letter.contacts`：邮箱带 `href: 'mailto:…'` 点了打开邮件；`copy: true` 的（微信、QQ）点一下复制，会提示「已复制」。
- 换头像：直接替换 `images/about/avatar.jpg`。

## 其他

- 前景家具（街机、桌子、画架、信箱等）是立体书纸片，翻开房间时从地板上立起来；每张纸片离墙多远、先后顺序在 `POPS` 里改（`d`、`delay`）。
- 加一间屋：复制一个房间对象，`scene` 用已有的场景之一。
- 封面点一下推门进来；← → 键 / 两侧箭头 / 手机左右滑动翻房间；顶部小圆点可直接跳房间。
- 点房间里的主角物件（或底部提示）推进去看作品；推进后 ← → 仍可换房间；Esc 或右上角 × 退出。
- 网址带 `#posters`、`#illustration`、`#product`、`#interactive`、`#about` 可直接打开某一间。
